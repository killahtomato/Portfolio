01. About

Hello! I'm Brandon, a customer-focused IT professional and part-time tool builder based in Harrisburg, PA. My career has been built around one core idea: making complex systems simple for the people who use them every day.

I started in remote technical support, moved into POS system management, and spent the last few years building tools, documenting processes, and training clients at Shift4 and Pure Technology.

Away from work, I'm rarely ever really "off", I like building things that solve problems I actually have. That's how Tomato Play (a CLI streamer for anime, movies, and TV), Tomato Media Ripper (a desktop downloader for social media), and ZZZ Codes (a redemption code finder) came to be. Each one taught me something new, shell scripting at a deep level, scraping and decryption, multi-threaded fetching, and polished GUI design.

I'm always looking for new challenges, especially in remote roles where accuracy, good communication, and a knack for automation matter most.

Tomato Media Ripper

Desktop GUI app for downloading video and audio from Twitter/X, TikTok, Instagram, and Facebook. Features a dark-themed Swing interface with pre-download preview (thumbnail, title, duration), multiple quality presets, async downloads with progress tracking, and persistent download history.

Tomato Play (tp)

Full-featured CLI tool for searching, browsing, and streaming anime, movies, and TV shows from 8 online sources. Resolves HLS streams via custom decryption, supports fuzzy search with progressive relaxation, marathon mode, per-episode resume, watch history, and an interactive home menu, all in a single POSIX shell script.

POSIX Shell · curl · mpv · HLS Streaming

ZZZ Codes

Multi-source redemption code finder for Zenless Zone Zero. Scrapes 11 gaming sites plus DuckDuckGo, Bing, and Mojeek in parallel, then uses context-aware extraction and cross-source scoring to identify active codes. Features a polished Swing GUI with copy-to-clipboard, redeem links, and redeemed-code tracking.

Java · Swing · HttpClient · Parallel Scraping
